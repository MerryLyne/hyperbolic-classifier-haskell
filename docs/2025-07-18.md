### Gensim

Gensim is an open source library in python including a poincare Pmbedding, so we will use this to check if there is an issue with our dataset
https://github.com/piskvorky/gensim/blob/develop/gensim/models/poincare.py

### Content

- `mon_dataset.csv` : dataset file CSV with a `is_hypernym`column.
- `glove.6B.100d.txt` : pre-traied GloVe file (100).
- `test_dataset.py` : Python script used to load data, generate embedding and calculate the Poincare distance
- `resultats_embeddings_poincare.csv` : result file
- `Dockerfile.python` : Dockerfile containing `gensim`, `numpy`, `pandas`, etc.
